# Clima Agora

Base inicial de uma app de clima feita com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` - estrutura da interface
- `style.css` - estilos e responsividade
- `app.js` - interacao inicial e dados de exemplo

## Como usar

1. Abra `index.html` no navegador.
2. Depois, voce pode ligar esta base a uma API de clima.
